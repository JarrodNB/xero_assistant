# Jev evals

Python files here use the module docstring in `backend/AGENTS.md`. Every function and method has a one-line docstring.

Each Jev use has its own package. A new use gets a new package here rather than more cases in an existing dataset. A Jev eval must apply the same provider-facing protection and formatting as its production use.

## Packages

- `user_message/` — the strict-policy screen of the user message before the chat model runs
