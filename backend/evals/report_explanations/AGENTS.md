# Report explanation evaluations

Synthetic financial reports only. `deterministic.json` is an offline rendering/numeric-fidelity golden dataset; `judge.json` is a distinct question/rubric dataset for opt-in live selector and judge assessment. Never run evaluation workflows from production requests. Run `python -m evals.report_explanations.run` through Docker for offline CI checks. `--scoring judge --live` is paid and explicitly opt-in. Use the separately configured report model snapshot and existing shared 12-request/12-tool/20k-token bounds. Judge budget is two requests/2k tokens, 20s; whole case 60s and dataset 900s. Retain only case booleans, prompt/model identifiers and timing under ignored evals/artifacts; no prompts, labels, answers, exceptions or judge reasons. Purge after 30 days. All functions and modules follow backend headers/docstrings.
