# Report tools

Expose read-only `compare_profit_and_loss` and `compare_balance_sheets` separately from invoice reads. Ordinary parent chat receives a typed value-free `/performance` handoff. Only the isolated report fact-selector receives bounded protected labels and evidence keys from freshly refetched, request-local comparison context. Never return financial figures, private IDs, raw reports, or write capabilities to a free-prose model. HTTP and context resolution share ReportService rate, byte, result and deadline limits. Follow backend source headers/docstrings.

`compare_profit_and_loss.py` and `compare_balance_sheets.py` each own one registrar. `payload.py` owns strict handoff/evidence contracts and request-local fact access. `__init__.py` combines registration only. Context preparation applies the 12k character cap; emitted evidence keys/labels/directions are only the selected account, metrics, top five and largest expense. Results explicitly identify omitted account details.
